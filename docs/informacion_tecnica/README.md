# Información técnica y material adicional

Esta carpeta no es necesaria para instalar o utilizar la aplicación. Conserva la información que necesitan desarrolladores, colaboradores y agentes de programación.

## Para agentes de programación

- [`agentes/PROMPT_IMPORTAR_VEHICULO_CON_IA.md`](agentes/PROMPT_IMPORTAR_VEHICULO_CON_IA.md): prompt completo para integrar otro coche.
- [`agentes/GUIA_TECNICA_INTEGRACION_CON_IA.md`](agentes/GUIA_TECNICA_INTEGRACION_CON_IA.md): método, fuentes, validación y reglas de seguridad.

## Arquitectura

- `arquitectura/especificación_maestra_del_proyecto.md`: especificación completa.
- `arquitectura/arquitectura_y_reglas_diagnostico.md`: reglas de análisis y evidencia.
- `arquitectura/roadmap.md`: evolución prevista.
- `arquitectura/adr/`: decisiones de arquitectura.

## Compatibilidad y ejemplos reales

- `compatibilidad/guia_hardware_y_compatibilidad_garaje.md`: adaptadores y vehículos.
- `compatibilidad/catalogo_metricas_passat_b6_bkp.md`: catálogo investigado para una variante concreta.
- `compatibilidad/VOLKSWAGEN_KWP2000_BKP.md`: transporte y validación KWP2000.
- `compatibilidad/VOLKSWAGEN_UDS_CBAB.md`: notas UDS para otra variante.

Los documentos del Volkswagen Passat no significan que el programa sea exclusivo de ese coche. Se conservan como implementación real, evidencia técnica y referencia para que un agente pueda integrar otros vehículos sin empezar desde cero.

## Compilación, publicación y pruebas

- `compilacion_y_pruebas/DESKTOP_BUILD.md`: creación del paquete Windows.
- `compilacion_y_pruebas/PRUEBA_VLINKER_FS.md`: prueba con adaptador real.
- `compilacion_y_pruebas/PUBLICATION_CHECKLIST.md`: comprobaciones antes de publicar.
- `compilacion_y_pruebas/TROUBLESHOOTING.md`: diagnóstico técnico de errores.
